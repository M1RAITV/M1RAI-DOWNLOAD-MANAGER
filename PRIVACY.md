# Privacy — M1RAI Download Manager

M1RAI Download Manager is designed to operate locally on the Android device.

## Current prototype behavior

- The user supplies a direct HTTP or HTTPS URL.
- The app passes that URL to Android's system DownloadManager to perform the transfer.
- The requested file is saved in the device's public Downloads location.
- The app does not currently require an account.
- The app does not currently include advertising, analytics, or an M1RAI-operated backend.

The website or server hosting a requested file will receive the network request and may process standard connection information such as IP address and request headers. Android and the device manufacturer may also process download and notification information as part of operating-system services.

## Future changes

This notice must be updated if analytics, advertising, crash reporting, accounts, remote services, or additional data processing are introduced. The Google Play Data safety declaration must accurately match the released app and every included SDK.
