# Contributing

Contributions are welcome.

- Check existing issues before starting major work.
- Keep pull requests focused and explain the problem being solved.
- Add tests or reproducible verification steps.
- Include screenshots for user-interface changes.
- Preserve third-party notices and check licences for all new dependencies.
- Do not add features that bypass DRM, paywalls, authentication, private access, or platform protections.
- Never claim a feature works without evidence.

The project uses Kotlin, Jetpack Compose, Gradle, and Android SDK. Build validation is performed with GitHub Actions.

Be respectful and constructive in all project discussions.
